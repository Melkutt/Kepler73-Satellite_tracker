📡 Rotator — Az/El tracking

⚠ Not tested on real hardware – use at your own risk. Try the Hamlib dummy rotator (rotctld -m 1) first and keep STOP within reach.

Kepler73 points a Hamlib rotctld at the selected satellite. Start it first: rotctld -m 1 for a dummy rotator, or rotctld -m <model> -r <COM port> for a real one. Default port 4533.

ℹ How do I start rotctld?

rotctld -m 1 — dummy rotator, just to check the link.

rotctld -l lists every supported controller and its model number, e.g. rotctld -l | findstr /i yaesu.

rotctld -m <model> -r <COM port> -s <baud> — -r is the serial port to the rotator controller, not the TCP port here (stays 4533). Add -vvvvv to debug.

⏺ Auto-track passes

Tick the satellites you want from any of your modules. For every pass whose maximum elevation reaches the threshold, Kepler73 selects the satellite (switching to its module if needed), starts the rotor and CAT Doppler, and runs your commands – for example a script that starts and stops an SDR recording. If two passes overlap, the one with the higher elevation wins. Weather satellites: try 20–25°, SSTV/SSDV: 10–15°.

⚠ Rotor and CAT are not tested on real hardware – try the Hamlib dummy rotator / rig first. After a pass the rotor stays in tracking mode and parks itself below its "Track above El"; CAT goes back to what it was.

The command is started directly (no shell, not waited for). Placeholders: {sat} {norad} {module} {max_el} {aos} {los} (UTC, 20261031T013338Z) {duration} {down_mhz} {event}. The same values are also set as environment variables K73_SAT, K73_NORAD, K73_MAX_EL, K73_AOS_UTC, K73_LOS_UTC, K73_DOWN_MHZ, K73_EVENT …

🛰 About Kepler73

Kepler73 v0.5 — a local satellite tracker for amateur-radio use, by SA1CKW. Everything runs and is cached on your machine; nothing is sent to any cloud.

⚠ Radio / CAT and Rotator control are new and have not been tested on real hardware – use them at your own risk. Try the Hamlib dummy devices first (rigctld -m 1, rotctld -m 1) and keep the STOP ROTOR button within reach.

Getting around

  • Pick a satellite in the left sidebar for its ground track, footprint, polar view and next pass.
  • The two checkboxes in the list: Alarm (left) sounds an alert shortly before that satellite rises – off for new satellites, tick the ones you care about; Track (right) keeps the map centred on it. The list is sorted by next pass: whoever comes next (or is overhead) is on top.
  • The right panel shows transponders, live Doppler and the pass — the 📌 pins it open beside the map.
  • Modules (Modules menu) are named satellite groups.
  • Your own data: ＋ in the transponder panel adds a transponder you found yourself (marked ✎ manual, kept when SatNOGS is refreshed); 📝 Add note puts a reminder on a satellite (📝 / ❗ in the list). Satellites menu → Export / Import my transponders & notes moves both to another computer.
  • Offline station: Settings → Offline station stops every internet lookup. On a computer with internet use Satellites → Export offline data pack (SatNOGS transponders + catalogue, one small ZIP), carry it over on a USB stick and Import it on the station. Element sets come from TLE sources – files, network shares or a LAN web server, one per line. A built-in world map (Natural Earth) shows even when no map tiles are cached (Map menu → Built-in offline map); detailed tiles exist only for areas you have browsed before.
  • Search & add and SatNOGS lookup pull satellites from Celestrak or the SatNOGS catalogue; or load a local TLE file.
  • Pass simulator (bottom-left) scrubs any pass up to a year back.
  • Auto-track (Satellites menu): tick satellites from any module and a minimum maximum elevation (e.g. 20° for weather satellites, 10° for SSTV/SSDV). For every pass that reaches it, Kepler73 selects the satellite at AOS, switches module if needed, starts the rotor / CAT Doppler and runs your own start and end commands – e.g. a script that starts and stops an SDR recording. Overlapping passes: the higher one wins. Off by default.
  • Radio / CAT sends the Doppler-corrected frequency to a Hamlib rigctld; Rotator points a rotctld at the selected satellite (Settings menu). Both are untested on real hardware.
  • Settings — observer location (map picker), min elevation, alarm, the TLE source and its list of sources, and the offline-station switch.

Data — orbital elements from Celestrak, transponders from SatNOGS, map tiles from OpenStreetMap / Esri, propagation via python-sgp4. Cached under data/, so it degrades to offline use.

📻 Radio / CAT — Doppler tuning

⚠ Not tested on real hardware – use at your own risk. Try the Hamlib dummy rig (rigctld -m 1) first.

Kepler73 sends the Doppler-corrected frequency of the selected satellite to a running rigctld (Hamlib).

ℹ How do I start rigctld?

rigctld is Hamlib's radio-control daemon. It talks to your radio over a serial / USB (COM) port and exposes it on a TCP port (default 4532) that Kepler73 connects to. Run it once and leave the window open.

Test without a radio:
rigctld -m 1  — model 1 is a dummy rig, just to check the link.

Find your radio's model number:
rigctld -l lists every supported rig. Filter it, e.g. rigctld -l | findstr /i 706.

Real radio:
rigctld -m <model> -r <COM port> -s <baud>
e.g. rigctld -m 3011 -r COM8 -s 19200 for an IC-706MKIIG. -r is the serial COM port to the radio — not the TCP port in this dialog, which stays 4532. -s is the serial speed and must match the radio's CI-V / CAT menu setting. For COM10 and higher use \\.\COM10.

Won't connect? Add -vvvvv to see what rigctld is doing. Full reference: hamlib.github.io · Hamlib wiki
